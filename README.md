# Hi, I'm Welder Oliveira 👋

**Backend Engineer** · Distributed Systems · High-Scale Architecture

---

Sou Backend Engineer com sólida experiência no desenvolvimento de sistemas distribuídos, microsserviços e aplicações de alta performance em ambientes de alta escala e missão crítica.

Minha atuação é fortemente voltada para arquitetura de software, modernização de sistemas legados, otimização de performance, redução de custos em cloud e construção de soluções robustas que geram impacto real para o negócio.

Tenho experiência prática com milhões de requisições e eventos diários, atuando com **PHP** (Laravel, Hyperf, Symfony), **Python**, **Apache Kafka**, **Redis**, **Kubernetes**, **Docker** e ecossistema **AWS**, sempre com foco em escalabilidade, confiabilidade e observabilidade em produção.

Ao longo da minha trajetória, participei da evolução de arquiteturas monolíticas para microsserviços, implementação de sistemas orientados a eventos, processamento assíncrono, estratégias de deploy seguro e melhoria contínua de ambientes produtivos complexos.

I'm a Backend Engineer with solid experience building distributed systems, microservices, and high-performance applications in large-scale, mission-critical environments. I focus on software architecture, legacy modernization, performance optimization, cloud cost reduction, and solutions that deliver real business impact.
